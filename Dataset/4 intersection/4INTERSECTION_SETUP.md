# 4-Intersection Network Setup Guide

## Overview
This document describes the 4-intersection grid network that has been added to your traffic simulation system.

## Network Structure

The network consists of 4 intersections arranged in a 2x2 grid:

```
    TL1  ----  TL2
     |          |
    TL3  ----  TL4
```

### Intersection Positions
- **TL1**: Top-left (-200, -200)
- **TL2**: Top-right (200, -200)
- **TL3**: Bottom-left (-200, 200)
- **TL4**: Bottom-right (200, 200)

### Each Intersection Has:
- 4 incoming directions (East, West, North, South)
- 2 lanes per incoming direction (8 incoming lanes total)
- 4 outgoing directions
- 1 lane per outgoing direction
- Traffic light control with 4-phase cycle
- 8 induction loop detectors (2 per incoming direction)

## Files Generated

1. **Network Files:**
   - `4intersection.nod.xml` - Junction definitions
   - `4intersection.edg.xml` - Edge definitions
   - `4intersection.con.xml` - Connection definitions
   - `4intersection.net.xml` - Compiled network (generated by netconvert)

2. **Configuration Files:**
   - `4intersection.sumocfg` - SUMO simulation configuration
   - `4intersection_traffic_lights.add.xml` - Traffic light programs
   - `4intersection_detectors.add.xml` - Detector definitions

3. **Traffic Files:**
   - `4intersection_routes.rou.xml` - Vehicle routes and flows

## Traffic Patterns

### Local Traffic
Each intersection has local traffic with vehicles:
- Entering from external points
- Making turns (left, right, straight) within the intersection
- Exiting to external points
- Flow rate: 1 vehicle every 8-15 seconds per route

### Inter-Intersection Traffic
Vehicles travel between intersections:
- **Horizontal routes**: TL1↔TL2, TL3↔TL4
- **Vertical routes**: TL1↔TL3, TL2↔TL4
- **Diagonal routes**: TL1↔TL4, TL2↔TL3
- Flow rate: 1 vehicle every 12-25 seconds per route

### Total Vehicle Load
- **32 local routes** (8 per intersection × 4 intersections)
- **12 inter-intersection routes**
- **Total: 44 active routes** with continuous vehicle generation
- Expected: **~200-400 vehicles** in the network during peak simulation

## Configuration

The 4-intersection network is configured in `src/config.py`:

```python
'4intersection': {
    'sumo_config': '4intersection.sumocfg',
    'network_file': '4intersection.net.xml',
    'route_file': '4intersection_routes.rou.xml',
    'traffic_lights': ['TL1', 'TL2', 'TL3', 'TL4'],
    'lanes': [32 incoming lanes],
    'detectors': [32 detectors],
    'control_mode': 'multi',
    'state_dim': 137,  # Auto-calculated
    'action_dim': 8
}
```

## Usage

### In Streamlit App
1. Open the Streamlit app (`python start.py` or `streamlit run app.py`)
2. Select "4-Intersection Grid Network" from the dataset dropdown
3. Choose a control strategy (Fixed-time, Adaptive, or DQN)
4. Click "Start Simulation"

### Programmatically
```python
from src.config import SimulationConfig
from src.traffic_simulator import TrafficSimulator

# Set dataset
SimulationConfig.set_dataset('4intersection')

# Create simulator
simulator = TrafficSimulator(use_gui=True, dataset='4intersection')

# Run simulation
metrics = simulator.run_simulation(duration=600, strategy='DQN')
```

## Traffic Light Control

All 4 intersections use the same 4-phase cycle:
1. **Phase 0** (30s): East-West green
2. **Phase 1** (5s): Yellow transition
3. **Phase 2** (30s): North-South green
4. **Phase 3** (5s): Yellow transition

The RL agent can control all 4 intersections independently or in coordination.

## State Space for RL

For the 4-intersection network:
- **32 lanes** × 3 features (count, queue, speed) = 96 dimensions
- **32 detectors** × 1 feature (occupancy) = 32 dimensions
- **4 traffic lights** × 2 features (phase, remaining time) = 8 dimensions
- **Time** = 1 dimension
- **Total: ~137 dimensions** (auto-calculated by simulator)

## Performance Considerations

- The 4-intersection network is more computationally intensive than a single intersection
- RL training will take longer due to larger state space
- Consider using GPU acceleration for DQN training
- Simulation runs at ~1 second delay in GUI mode for visualization

## Network Validation

To validate the network, run:
```bash
netconvert -n 4intersection.nod.xml -e 4intersection.edg.xml -x 4intersection.con.xml -o 4intersection.net.xml
```

Or test in SUMO GUI:
```bash
sumo-gui -c 4intersection.sumocfg
```

## Troubleshooting

1. **Network not loading**: Check that all XML files are in the project root directory
2. **No vehicles appearing**: Verify routes file is correctly referenced in sumocfg
3. **Traffic lights not working**: Check that traffic_lights.add.xml is included in additional-files
4. **RL state dimension mismatch**: The simulator will auto-calculate; ensure lanes and detectors match config
